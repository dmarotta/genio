Genio itself is released under the [MIT License](LICENSE). It is built on the open-source packages below and

## Optional components Genio downloads on request

These are not part of this repository and are fetched only after you click Download (see [docs/voice.md](docs/voice.md)).
Each is verified against a pinned SHA-256 and stored in Genio's own data folder.

**The natural voice's runtime download includes GPL components.** The sherpa-onnx addon has espeak-ng built in, and
espeak-ng is licensed GPL-3.0-or-later. Those components are not part of this repository's MIT code and Genio does
not distribute them: you download them from their publishers after saying yes, and they run in a separate helper
process. Anyone who bundles the addon or model with Genio has to meet the GPL-3.0 for that part. The reasoning is in
[docs/voice.md](docs/voice.md).
