# Chat model catalogue

Chat and ally model pickers share a searchable catalogue. Provider chips filter provider / model rows, with exact IDs on hover. The default list ranks four models per route by newest numeric family/version, then strength tier; older major families are legacy. Show all models at the bottom restores older public models and persists across pickers and restarts. Aliases, dated/latest duplicates and hidden/internal models are excluded. Signed-in providers sort first. Only fresh, connected Claude entries can drive a chat. Gray account rows, including providers without discovered models, open Systems Accounts. Connected non-Claude rows show chat driver coming soon without switching. Free candidates also link to Accounts. The shared portal fits narrow chat, ally and floating Inventory panes. A catalogue candidate does not prove inference entitlement or quota.

The main-process service keys entries by runtime, provider and canonical model ID. Claude aliases, including default/opus, collapse to one model while remaining searchable. Discovery uses a running SDK query when present; before the first conversation it creates a metadata-only query using the chat's configured executable (or the bundled SDK default), with no tools or prompts. Codex uses app-server initialization and all model/list pages. Gemini uses ACP initialization and session/new model options; authentication failures produce Sign in, with no invented defaults. OpenCode's verbose catalogue supplies capabilities and zero-cost anonymous candidates. OpenRouter discovery requires a stored Genio key; its presence is labelled separately from verified inference access.

The cache lasts five minutes and coalesces concurrent requests. Opening/refreshing the picker, focus and a bounded polling interval recheck it. Login/logout completion and key changes invalidate it. Failed refreshes retain previous entries with their original source time and a stale label, and disable chat selection. Usage percentages and reset times come exclusively from the existing Claude/Codex limit reports, with evidence age; all other cases say Usage unknown.

Same-runtime changes use existing between-turn controls and per-chat persistence. Model changes reset the effort override; discovered per-model effort levels populate the effort selector, and unsupported inherited effort falls back to automatic in the runtime. The AFK Bot retains its independent Claude settings.

Tests cover aliases, provider identity, hidden entries, filtering, auth failures, stale retention, TTL, and mocked Codex/Gemini metadata protocols. No inference requests are made in tests. Run `npm run typecheck`, `npm test`, and `npm run build`. When running inside a Genio unit, remove inherited `GIT_CONFIG_COUNT` / `GIT_CONFIG_KEY_0` / `GIT_CONFIG_VALUE_0` from the test process environment only so git-hook fixture tests do not chain the enclosing unit's coauthor hook.
