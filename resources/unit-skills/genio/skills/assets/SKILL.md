# Assets

Use this workflow whenever the player asks for new media or a variation in a project.

1. Resolve the project and request. Inventory selection supplies references; its current folder is a destination only if the player says "here" or names that folder. Read `asset_info` for references and `assets_find` for neighbouring work.
2. Choose a provider. Ordinary images, sprites, icons, concepts and cutouts use **imagegen-codex** on the ChatGPT plan. Read `../imagegen-codex/SKILL.md`. Use **fal** for seamless/PBR textures, 3D, audio/music, video, exact size/seed, upscaling and other specialised endpoints; read `../fal/SKILL.md`. Motions and rigged characters use **uthana**; read `../uthana/SKILL.md`.
3. Art Bible: when the project has `.genio/art-bible.md`, every generator applies it automatically (style text, palette, the asset type's references; recorded as `art_bible` in provenance). Pass the asset type (`asset_type` in Genio's tools, `--type` in the unit helpers) so its section applies, and read the bible for that type before writing the prompt: keep the prompt about the subject, not the style. `art_bible: false` / `--no-bible` only when the player or mission says so. No bible means nothing is applied: never create or edit one unless asked (Genio's `art_bible` tool, only on the player's request).
4. Choose the destination yourself with `asset_locate(world, kind, name, hint)`. Use the current project type and engine root, configured folders, then measured sibling naming and engine fallbacks. Pass an actual extension when known. Review the reasons and warnings. See `references/placement.md` and `references/engines.md`.
5. Call the provider API with `world`, the chosen `place`, and `player_words` quoting the asset request. Tools return immediately with a background run id. `generation_status(run)` reports completion and paths. There are no drafts, Keep actions, or undo tools. Results are saved directly and left uncommitted. Report paths and cost; never claim quality from metadata alone.
6. FAL: `fal_models(world, job?, query?, endpoint?)` supplies catalogue, schemas and prices. Use schema field names and defaults; `fal_generate(world, endpoint, input, place, player_words)` validates and prices before submitting. Uthana: use `uthana_motion` or `uthana_character`. Codex: `generate_image(prompt, refs?, transparent?, count?, world, place, player_words)`; omit project for chat-only images.
7. Every paid request asks the player first, whatever the amount (FAL, Uthana; there is no ask-below threshold). The one-click chat quote is bound to the request and estimate. A typed approval goes through `approve_run(run, player_words)` with the player's actual words. Never approve your own quote. Monthly caps are hard stops. Codex images never ask; respect project Codex opt-out. No automatic paid retries after uncertain failure.
8. `asset_place(run, output, world, path, player_words)` can place an already generated output. An existing target is refused unless the player explicitly confirms overwriting that specific file; only then provide their words as `overwrite_words`. Prefer another collision-free name. Never use it for arbitrary local files, code, scenes, prefabs or .meta files. Bot cannot generate, approve or place.

Genio handles up to four outputs and at most USD 2 per request. Delegate batches, conversions, materials referring to textures, import settings, Humanoid setup, scenes, prefabs and code to a Build unit. Never commit from Genio. Units work only in their isolated copy and commit assets with provenance/spend. They use the provider CLI helpers, not Genio's chat tools, and spend only under the spend grant the player approved for them: before any paid call (FAL, Uthana, the Sound Studio's FAL steps) a unit without enough grant asks with `needs-decision [key=spend]` and JSON metadata `{"spend_usd": <amount>, "details": "<plan, estimate>"}`, then stops until the player answers; the helpers refuse with exit 6 otherwise. Codex images are free for units too: no grant, no question. Never approve a unit's spend for the player. for Uthana motions and characters that is `../uthana/scripts/uthana.mjs` (read `../uthana/SKILL.md`), never an improvised client.

Unit placement uses the same `suggestLocation` helper in `../../lib/genio-world.mjs`, or `fal.mjs locate --world . --kind audio --name door.wav --engine unity --engine-root Game`. Read-only `catalogue` lists bundled FAL models. Do not edit project generation config or recipes.
